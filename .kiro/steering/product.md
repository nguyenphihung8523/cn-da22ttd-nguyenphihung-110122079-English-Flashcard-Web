# Product Overview

English Flashcard Web is a fullstack language learning application for Vietnamese users to study English vocabulary through flashcards, quizzes, and speaking practice.

## Core Features

- User authentication with JWT (register/login)
- Flashcard management (CRUD operations)
- Learning modes: flashcard review, quiz, speaking practice
- Progress tracking with level system (basic, intermediate, advanced, communication, specialized)
- User profiles with favorites, mistakes tracking, and statistics
- Offline-first design (runs on localhost)

## User Interface

- Vietnamese language interface
- Tailwind CSS for styling
- Responsive design with Header/Footer layout
- Protected routes requiring authentication
- Dashboard-centric navigation

## Key User Flows

1. Register → Login → Dashboard
2. Browse flashcards by level/topic → Study cards
3. Take quizzes to test knowledge
4. Practice speaking pronunciation
5. Track progress and review mistakes
